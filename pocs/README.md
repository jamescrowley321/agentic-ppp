# POCs

Each POC is one folder: `pocs/track-1/<name>/` for Track 1, `pocs/track-2/<name>/` for Track 2. Its README says how to run it and has a "Remove it" section. Removing a POC means deleting its folder and stopping its processes, timers or routines, and nothing else. A POC never touches anything outside its folder, except what its README names.
